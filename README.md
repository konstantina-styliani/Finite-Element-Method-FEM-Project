# Finite-Element-Method-FEM-Project
Course: Computational Electromagnetics
 Developed a computational code based on the Finite Element Method (FEM) for the numerical solution of electrostatic and electromagnetic problems.
Solved electrostatic problems, including a coaxial cable with air as the dielectric and a finite-width parallel-plate capacitor, calculating the total electrostatic energy and capacitance per unit length, as well as visualizing the electric field vector $\mathbf{E}$.
Investigated electromagnetic wave propagation in a circular waveguide by calculating and visualizing the first nine \textbf{TE} and \textbf{TM} modes, together with the corresponding electric potential distribution $\mathbf{\Phi}$.
Investigated the convergence of the numerical solution toward the analytical solution through successive mesh refinements, demonstrating the reduction of numerical error and improvement in solution accuracy.
Analyzed the scattering of an electromagnetic wave from an infinitely long, perfectly conducting circular cylinder using a first-order Absorbing Boundary Condition \textbf{(ABC)}, with visualization of the resulting total electromagnetic field.
